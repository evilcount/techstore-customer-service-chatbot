\# TechStore Plus Customer Service Chatbot



This project implements an initial customer service chatbot for TechStore Plus.



\## Features



\- Customer inquiry analysis

\- Sentiment analysis

\- Emotion detection

\- Query category classification

\- Urgency detection

\- Entity extraction

\- Personalized response generation

\- Conversation summary persistence in JSON format

\- Mock mode for local testing without API costs

\- Optional OpenAI/Claude integration



\## Project Structure



\- `TechStorePlus\_Customer\_Service\_Chatbot\_Project.ipynb`: main Jupyter Notebook

\- `requirements.txt`: Python dependencies

\- `.gitignore`: ignored local files and secrets
